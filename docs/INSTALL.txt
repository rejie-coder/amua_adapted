Amua 3.3.3 for Intel Mac — preview

Requirements: Intel x86_64 Mac,macOS 14 or later. Java,Python and Google's native
Antigravity runtime are bundled. This is not a native AppleSilicon build.

1. Drag Amua.app to Applications.
2. Eject the disk image and open the installed app.
3. Save new model work separately from originals.
4. In AI Workflow choose ChatGPT or Gemini, then Connect account.
   Gemini Accounts supports reconnect, add, switch and remove.

The outer app is ad hoc signed,not notarized. Review normal macOS Privacy &
Security first-launch controls if blocked. Do not disable Gatekeeper globally.
Google/OpenAI account eligibility and limits apply. No API-key fallback is used.
Manual modelling works without AI sign-in. Review scientific inputs and run
full original validation before calculations.
