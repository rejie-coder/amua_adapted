# Troubleshoot the Intel preview

## The app will not open

Confirm Intel x86_64 and macOS 14+. Check the download checksum, copy the app into Applications and eject the DMG before launch. The preview is not notarized; review the normal macOS Privacy & Security first-launch controls in [Installing](Installing.md). Do not disable Gatekeeper. Report the exact macOS version, app version and message without posting your support directory or credentials.

## An image produces an outline instead of the final tree

The PRELIMINARY source outline is intentionally incomplete. Wait for Proposal ready, then click Apply tree proposal. If the request failed, FINAL TREE NOT APPLIED states that explicitly. Retry starts a fresh outgoing review with the validation reason. Turn off workspace inclusion for an independent image model. Compare the transcribed values and separate dimensions before approving inputs.

## Copy/paste or dropped files are not attached

Focus the chatbox and use Command V or its right-click menu. Drop ordinary supported files directly into the question field. Wait for image preparation; the attachment count appears above the field. Use Select files / folder for directories. Unsupported file types, symlinks, remote file URLs, excessive counts or size limits produce an attachment message. Changing sources invalidates old request/proposal state. Physical OS clipboard/drop behavior still needs clean-desktop acceptance beyond controlled handler tests.

## OCR reports an unreadable scanned page

Actual scanned-PDF OCR remains an unresolved local test failure, previously reporting Vision/CoreVideo -6662. Do not treat an unreadable page as extracted evidence. Try a supported image source directly for visual interpretation and verify its values, or provide selectable text. Synthetic OCR recovery passing does not establish native recognition.

## Account or workspace sign-in fails

Use Accounts to select the intended saved connection or add a new account/workspace. Reauthorize the selected connection deliberately. Eligibility and workspace policy may block inference even after sign-in. Allow intended macOS Keychain access when prompted. Do not reset/delete shared credentials automatically. No silent paid API fallback is attempted.

## A model will not calculate

Open Questions and Review inputs. Unresolved context, unsupported expressions or image-derived values can keep the native review guard active. Structure approval cannot clear input review. Resolve the scientific questions, inspect values, then run full native validation. Do not remove the guard manually to force an unsupported calculation.

## A request appears slow

Progress-aware waiting allows long requests while meaningful data arrives. The default idle interval is three minutes and can be adjusted in AI Workflow. Status does not cancel; Stop discards late output. Retry is user-triggered and requests fresh review. Do not infer completion from a progress count or Run click.
