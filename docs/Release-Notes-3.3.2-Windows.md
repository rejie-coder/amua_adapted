# Amua 3.3.2 Windows tree display correction

OCD now restores original Amua's compact decision-tree spacing and honours left/right terminal alignment. The previous measured layout reserved too much room per row/column, making the same model far larger. Red decision squares, green chance circles and blue terminal triangles now have solid fills, black outlines and black connectors. Full node names remain editable and available as tooltips.

The Windows 3.3.1 whole-interface DPI scaling, larger chat/source fonts and responsive sidebar are retained. ChatGPT and experimental Gemini functionality is retained; Claude subscription integration remains unavailable. This update does not supply missing clinical inputs or alter the numerical calculation routines.

Extract the complete new ZIP into a new folder. Save and close the previous version, then open Amua/Amua.exe. Use Windows' recommended display scale and restart after changing display scaling. The previous 3.3.1 assets are preserved.

Release gates include the existing native Windows suite plus a real GUI comparison of all 52 node/parent positions against original Amua in both terminal-alignment modes, solid node-colour pixel assertions and tree/Markov painter checks. The release is published only after these checks, package integrity and uploaded-ZIP readback pass.

Unsigned Windows x64 preview. Physical acceptance on the user's laptop and live Gemini account acceptance remain pending.
