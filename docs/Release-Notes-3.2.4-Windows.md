Windows x64 preview of Amua 3.2.4, with bundled Java/Python, native GUI launcher, Windows Credential Manager, editable decision-tree/Markov models, original-engine calculations, built-in AI Workflow and chatbox paste/file drop.

Download **Amua-3.2.4-Windows-x64.zip**, extract the complete ZIP, then open **Amua/Amua.exe**. No administrator installation or system Java/Python is needed. Targets Windows 10/11 x64; native ARM is not included. The app is unsigned and may show an unknown-publisher warning.

Before publication, the native Windows workflow checks startup/single instance, process supervision, forced-stop snapshot deletion, Credential Manager, Unicode, package/source correspondence, original-engine equivalence, image review and clipboard/drop controllers, save boundaries and actual English Windows OCR. All required groups must pass. The accompanying verification reports, audit, source and SHA256SUMS document the result and explicit private/POSIX test skips.

Clean Windows desktop and live signed-in AI/image acceptance remain open. OCR depends on installed Windows language components; unknown confidence/unreadable pages require review. Scientific inputs and assumptions must be checked before calculation. Network/cloud-sync saves and power-loss durability are not established.

The Intel Mac v3.2.4 release remains available separately. Native Apple Silicon work follows Windows.
