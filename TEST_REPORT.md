# Windows 3.3.2 release verification

This release's authoritative native results are generated by GitHub Actions in `evidence/windows-checks.json` and attached as `windows-checks.json`. A release is blocked if any required group fails. Local cross-build checks are preparatory and do not prove Windows execution.

Required checks: the 22 existing Windows 3.3.1 groups (including actual GUI DPI-awareness state, native process/locking/credential guards, Gemini ACP initialization without an account, provider/workflow regression, clipboard/sidebar/atomic saves and eight original-engine results) plus four display groups. The new groups run actual original and corrected GUI OCD on a synthetic 52-node tree, require every node/parent coordinate to match for left and right alignment, assert stable repeat and unchanged scientific fields, verify saturated node-centre pixels, and exercise tree/Markov selected/collapsed painters at 50/100/200% rendering scale.

The reviewed display changes are confined to `tree/PanelTree`, `tree/TreeNode`, `markov/MarkovNode` and `gui/NodeAppearance`. Their compiled bytes are pinned separately; all other baseline numerical classes remain byte-identical. Package checks retain exact source and Windows PE/DPI verification. Portable ZIP integrity and every entry are checked, then the uploaded ZIP is downloaded and hashed before publishing.

No live Google/ChatGPT inference, clean desktop installation, physical laptop acceptance, Authenticode signing or scientific model acceptance is claimed by these automated checks. Synthetic fixture probabilities are not clinical estimates.
