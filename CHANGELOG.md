# Changelog

## 3.2.4 Intel Mac preview

- Correct desktop image-chat rejection caused by malformed clarification targets; preserve questions without writing values into guessed targets.
- Specify native decision/chance/terminal topology, separate Cost/QALY dimensions, source references and terminal payoff placement.
- Distinguish preliminary outlines from final proposals, prevent unchanged outlines contaminating a repeated Send, and keep Apply visible.
- Carry local validation reasons into a user-triggered fresh Retry; no automatic retry loop.
- Add chatbox text clipboard/context actions, asynchronous image/file paste and ordinary file drops with bounded local storage and no automatic send.
- Publish Intel source/build scripts, user documentation, wiki pages and a checked DMG preview.

Known limits: ad hoc signing/no notarization, pending clean-machine and live-account vision acceptance, and a retained local scanned-PDF OCR failure. Windows and native Apple Silicon are deferred in that order.

## Earlier local versions

3.2.3 hardened native field/update preservation, rejected ignored numerical fields, bound account/model approvals, protected source evidence and input review, and improved recovery limits. 3.2.2 introduced progress-aware idle waiting. These were local builds; this changelog does not assert prior public releases.
